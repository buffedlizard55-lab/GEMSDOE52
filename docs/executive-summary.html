1 · How to submit (for the day a file is approved)

A file is submitted only when its status says OK to submit: YES on the status page, and a selector has recorded that decision. The steps below are the ones the team follows. They are not yet tested on the DrivenData form from this sandbox.

  1. Check the file. It must be a single-band GeoTIFF, float32, EPSG:32611, with every value in [0, 1]. A previous upload was rejected with "Predicted values must be in range [0, 1]". Run the validator in the repository (scripts/verify_h88_file.py is the template) and confirm its output is 12/12 PASS.
  2. Check the SHA-256 of the file against the status page. A mismatch means the file has changed.
  3. Open the competition page: drivendata.org/competitions/306/competition-doe-gems (not fetched from this sandbox). Log in as the team account.
  4. Upload the .tif on the submissions page: submissions (not fetched from this sandbox).
  5. Enter the name and the note. The name must be unique on the team's history. The note must be at most 140 characters. The status page gives both fields for the approved file.
  6. Submit once and record the slot in the repository. Up to three submissions per week count against the limit, so each one is logged.
  7. Read the organiser score on the submissions page. That is the only ORGANIZER-CONFIRMED number. Record it with a receipt; every other number is HOLDOUT-DTI.
