What This Submission Does

This submission uses Multi-Scale Structural Concordance + Geothermal Proximity to detect potential fault locations:

  1. Computes oriented linearity at 4 spatial scales for gravity, magnetic, and DEM data
  2. Counts how many independent instruments show consistent linear features at each pixel
  3. Weights detections by proximity to 27,092 wells/springs with temperature data
  4. Excludes the catalogue ring (0 pixels within 200m of mapped faults)
  5. Emits 37,654 binary {0,1} pixels at the top-ranked locations
