Executive Summary — H87 Co-Training Wavelength Contrast

GEMSDOE52 · DOE GEMS Prize · 2026-10-10

1. What This Is

GEMSDOE52 is a fault-discovery system for the DOE GEMS Prize (DrivenData #306). The task: predict where unmapped geothermal-indicative faults exist in the GeoDAWN study area of northwestern Nevada. The scoring metric is a distance-weighted Tversky index (DTI) with α=0.2, β=0.8, R=300 m triangular kernel.

This submission (H87) implements a co-training framework between two independent views of the Earth, using disagreement as the discovery signal:

  • View A (geophysical): Gravity gradients, magnetic gradients, geodetic strain, basement depth, conductivity — sees subsurface structure
  • View B (surface): Multi-scale DEM wavelength contrast, slope, radiometric Th/K ratio — sees surface expression + alteration

2. Why Disagreement Matters

Following Blum & Mitchell (COLT 1998), when two views are each sufficient for the task and approximately conditionally independent given the class, their disagreements reveal the most informative unlabeled examples:

CaseInterpretationAction
A confident, B abstainsBuried fault beneath alluvial coverEMIT (discovery candidate)
B confident, A abstainsSurface artifact (road, erosion, lithologic contact)SUPPRESS (confounder)
Both confidentKnown/mapped fault (already in catalogue)Skip (already mapped)
Both abstainNo fault signalSkip

Independence verified: The Pearson correlation between View A and View B scores on the valid footprint is r = −0.140, well below the 0.60 abandonment threshold. The views are measuring genuinely different aspects of the landscape.

3. Novel Features

Multi-Scale Wavelength Contrast (never used in any prior)

The ratio of fine-scale (σ=1, ~100m) to coarse-scale (σ=8, ~800m) Hessian eigenvalue magnitude of the detrended elevation. This ratio is high where a sharp, localized feature (scarp, lineament) sits on top of a smooth regional surface, and low where the topography is uniformly rough or smooth at all scales. No prior submission in the 129-raster registry uses this transform.

Radiometric Th/K Ratio (used as raw band but never as ratio)

Hydrothermal fluids leach potassium from rocks along fault zones, elevating the Th/K ratio. The GeoDAWN airborne radiometric survey (DOI 10.5066/P93LGLVQ) provides K, Th, U, and total-count grids at 100m resolution. While some priors used the raw radiometric bands, none computed the Th/K ratio transform specifically targeting hydrothermal alteration.

6. Metric-Aware Placement

The DTI metric uses a 300m triangular kernel: k(d) = max(1 − d/R, 0) where R = 300m = 3 px. Each emitted dot earns credit only if it lies within 300m of a truth pixel, weighted by the kernel. The credit bar at the current best DTI (~0.28) is 0.2 × 0.28 = 0.056 — each dot must earn at least 0.056 kernel weight to raise DTI.

This submission uses:

  • Budget: 37,654 dots (same as the 0.2778 reference)
  • Spacing: minimum 3 px between dots (reduces redundant local coverage)
  • Catalogue collar: 200 m exclusion from all known fault pixels
  • Binary emission: {0, 1} — proven optimal at fixed budget (pinned in tests/test_metric.py)

8. Limitations & Next Steps

Known limitations

  • No holdout DTI score: This build receipt verifies format and uniqueness but does not run the spatially-blocked holdout evaluator. A holdout score would require running scripts/run_h87.py which is not yet written.
  • Catalogue proxy: The holdout's truth is the visible catalogue, so it cannot reward genuinely new faults — only structural extensions of known ones.
  • View A confounders: Gravity/magnetic gradients can arise from lithologic contacts without faulting. The co-training approach mitigates this by suppressing B-confident predictions.
  • No organizer score: The DTI value will only be known after portal submission.

Recommended next steps

  • Submit this file to the competition portal and record the actual score
  • Run the spatially-blocked holdout to get a projected DTI with confidence interval
  • If score > 0.28, investigate which geological zones the A-only dots concentrate in
  • Consider a variant with tighter catalogue collar (1px instead of 2px) to capture tip extensions
