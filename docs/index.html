📉 Conclusion for the competition goal (no spin)

Taking H88 and H89 together, on this footprint and this instrument, the potential-field/subsurface view carries no measurable catalogue-fault signal in either of the two representations tested (amplitude — the repository's nine prior failures — or directional-variogram boundary texture) at either lag family (100–300 m or 400–800 m). The brief's disagreement arm cannot donate from a donor that is not sufficient, and it does not.

Separately, the repository's own measurement explains why the holdout cannot promote anything here: the holdout hides catalogue components, while the competition scores faults the catalogue lacks — the champion h33-2-b2 earns 99.26 % of its credit outside every mapped fault's kernel. Cross-round Spearman between holdout DTI and the public board is −0.10. The number that has to move is credit per emitted pixel: 13.87 % → 15.95 % (+15 %), or the same credit at 32.6 % less mass. That is a detector problem; placement headroom is already within 4 % of its geometric optimum.

🚩 Irregularities flagged for review

IR-H88-001 — filesystem loses the first 4 KiB page of written channel files. 34 of 36 channel arrays in work/h88/features were found with flat indices 0–991 (992 float32 = 3,968 bytes = exactly one page after the 128-byte .npy header) reading 0.0 on disk while a fresh recomputation gave 0.959–0.985. The array-comparison write check passed, so the page was lost after verification. Fixed this round: the writer now compares raw file bytes against the in-memory image, and heal_channels() recomputes any channel whose digest moved. Re-running the fit and holdout after healing reproduced every number bit-for-bit (0.034799 / 0.128009 / 0.081910 / 0.164883 / 0.080426), which is the evidence that the published receipts were computed from correct bytes. This is a new instance of IR-H82-002 / IR-H84-003 and a strictly stronger guard.

IR-H88-002 — the lane's literal dot rule is uninformative against a universal-coverage probe. The single "duplicate" hit is 13gems_20261001_r13-lattice-s5_v2_nan-outside.tif (206,895 positive pixels). Measured this session: it lies within 3 px of 4,325,298 of 4,325,298 allowed pixels — 100.000 %. A control of 5,000 uniformly random dots from the same allowed set therefore scores near-3 px = 1.0000 against it. The literal rule is reported, not waived; excluding probes, the maximum is 0.3828 against the 0.70 bar. Extends IR-H85-009.

IR-H88-003 — band 6 tag is wrong. Band 6 is tagged tc — Tilt angle or total curvature — magnetic field derivative for edge detection, but its bytes carry Spearman 1.0000 with the GeoDAWN radiometric total-count grid (data/external/geodawn_rad_u8.tif band 4, USGS DOI 10.5066/P93LGLVQ). The repository therefore treats band 6 as View B per the brief's "any radiometric bands present in training_features.tif". Same finding as IR-H85-005; restated because it decides the view split.

IR-H88-004 — the previous round's home page claimed "VERDICT: PROMOTE" with no holdout. The H87 file (gems52-h87-cotrain-wavelength-thk-37654px-20261010T213656Z.tif) had a build receipt only — evidence/h87_build.json says "evidence_class": "HOLDOUT-DTI (not yet run…)". No H87 holdout receipt exists anywhere in the repository. The claim is corrected on this page, and H87 is marked research-only below.
