🔬 Hypothesis: Multi-Scale Structural Concordance + Geothermal Proximity

Why This Is Unique

This submission is NOT a rehash of the co-training approach (which failed View A sufficiency 7 times in this repository). Instead, it uses direct multi-instrument structural detection that is fundamentally different from any previous submission in this family of repositories.

Method

  1. Multi-Scale Structure Tensor — Compute oriented linearity at 4 spatial scales (σ=1,2,3,5 pixels) for gravity, magnetic, and DEM data using the structure tensor eigenvalue method.
  2. Cross-Instrument Concordance — At each pixel, count how many independent geophysical instruments (gravity, magnetics, DEM) show strong consistent linear features. Concordance across 2+ instruments is strong fault evidence.
  3. Geothermal Proximity — Weight detections by proximity to 27,092 wells/springs from the GDR 1391 INGENIOUS dataset. Hot springs far from cataloged faults indicate uncatalogued fault structures.
  4. Catalogue Ring Exclusion — Applied the critical lesson from h33-2-b2 (0.2778): pixels within 200m of mapped faults earn zero credit while paying the FP tax. Zero pixels within 200m of catalogue.
  5. Binary {0,1} Emission — Optimal per the metric algebra (continuous scores forfeit score).

🔧 Technical Details

Feature Engineering

  • Gravity: Isostatic anomaly (band 13), vertical gradient (band 11), horizontal gradient (band 18), slope (band 5)
  • Magnetics: RTP (band 2), TMI vertical gradient (band 9), total magnetic intensity (band 14)
  • DEM: Detrended elevation (band 12), slope (band 19)
  • Geothermal: 27,092 well/spring locations with temperature weighting

Structure Tensor

At each scale σ, compute the structure tensor J from the gradient field:

J = [Jxx  Jxy]
    [Jxy  Jyy]
where Jxx = Gσ * (∂I/∂x)², Jyy = Gσ * (∂I/∂y)², Jxy = Gσ * (∂I/∂x)(∂I/∂y)
Linearity = (λ1 - λ2) / (λ1 + λ2) where λ1 ≥ λ2 are eigenvalues

Concordance

At each pixel, count instruments with linearity above the 70th percentile. Add orientation agreement bonus for pairs that are both strong and aligned (|cos θ| > 0.5).

Emission

Top-k binary emission at k=37,654 (matching h33-2-b2 budget), with catalogue ring exclusion (2-pixel buffer around mapped faults).
