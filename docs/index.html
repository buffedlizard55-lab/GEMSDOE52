01 / the finding that explains the lane

View A does not transfer

AUC 0.516 vs 0.684

Mean out-of-fold AUC inside a held-out quadrant: View A (potential field / subsurface) 0.516, View B (surface + radiometrics) 0.684. In-sample View A reaches 0.948. A view that fits its own quadrant and predicts chance in the next one is not a sufficient view, so Blum–Mitchell transfer has nothing to give. This is the mechanism behind four previous failed disagreement arms.

The file describes band 6 as a magnetic tilt derivative. Measured against the pinned external GeoDAWN grids it is rank-identical to total count (ρ = 1.0000) and uncorrelated with tilt (ρ = 0.0175). It belongs in View B, and it is the reason View B is the view that transfers.

The 0.2778 question

Precision, not detection.

Measured from the restored bytes: the reported-0.2778 champion h33-2-b2 is a strict subset of the reported-0.2600 file (37,654 ⊂ 44,090 off-catalogue px), which is itself a strict subset of the reported-0.1922 parent field (⊂ 121,131 px). The champion added no pixel and deleted 6,436 — every one of them between 100 m and 200 m from a mapped trace, measured. Its own nearest dot is 223.6 m away. DTI = T / (0.2·(T+S−M) + 0.8·(|G|−T)) rewards that pruning because 0.8·|G| is a fixed floor in the denominator.

Can this file beat it? Break-even credit density at 37,600 dots is 0.0907–0.1295 per emitted pixel (8.3–5.6× uniform random). The arm's only empirical density estimate comes from a simulator that measured Spearman −0.10 against the owner-reported board, and organiser-tied evidence gives no information about pixels outside all thirteen scored files. So the honest projection is an interval whose lower end is 0. No leaderboard gain is claimed.

Attribution strength is not uniform: 2 of 13 owner-reported scores are hash-linked to the bytes held; the champion's token e5eb6e7e matches none of six hash conventions of the file we hold, and GEMSDOE32's own page says no organiser score exists.
