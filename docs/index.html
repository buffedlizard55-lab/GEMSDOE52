Method

🔧 Technical Details

Feature Engineering

  • Gravity: Isostatic anomaly (band 13), vertical gradient (band 11), horizontal gradient (band 18), slope (band 5)
  • Magnetics: RTP (band 2), TMI vertical gradient (band 9), total magnetic intensity (band 14)
  • DEM: Detrended elevation (band 12), slope (band 19)
  • Geothermal: 27,092 well/spring locations with temperature weighting

Structure Tensor

At each scale σ, compute the structure tensor J from the gradient field:

J = [Jxx  Jxy]
    [Jxy  Jyy]
where Jxx = Gσ * (∂I/∂x)², Jyy = Gσ * (∂I/∂y)², Jxy = Gσ * (∂I/∂x)(∂I/∂y)
Linearity = (λ1 - λ2) / (λ1 + λ2) where λ1 ≥ λ2 are eigenvalues

Concordance

At each pixel, count instruments with linearity above the 70th percentile. Add orientation agreement bonus for pairs that are both strong and aligned (|cos θ| > 0.5).

Emission
