3 · Why the “Predicted values must be in range [0, 1]” error cannot fire on this file

That rejection means the portal decoded at least one pixel outside [0, 1] — in practice a continuous probability raster, a NaN that decoded to a sentinel, or a file written on the wrong grid so that the portal read nodata. This file is written by gems52.grid.write_geotiff, which refuses to write unless the array is float32, is exactly 3,730 × 3,292, is finite everywhere, and has min ≥ 0 and max ≤ 1; it then re-reads the file from disk and the receipt above is that re-read, not the array in memory. gates.format_report compares bands, dtype, CRS, shape, transform and bounds against data/sample_submission.tif independently. 4 · The decision, in the repository’s own terms

DOWNLOAD YES · THE PORTAL WILL ACCEPT THIS FILE YES · SPEND A SLOT NO.

The file itself is portal-safe and is served above. What fails is the frozen promote rule, on two clauses that are not waivable:

  • S1 sufficiency FAIL — View A out-of-quadrant AUC mean 0.5281, minimum 0.4896, against thresholds mean ≥ 0.60 and fold ≥ 0.55. When this fails the Blum–Mitchell premise fails and the disagreement arm is noise-dominated. H61 measured 0.5163, H63 0.5362, H64 0.5230.
  • HOLDOUT-DTI vs single_B — candidate -0.101474, 95 % CI [-0.123610, -0.080051]. The brief says never spend a slot on an idea that has not beaten the current holdout best.

Read against that, one measured fact has to be stated every time: knowledge/10 §5 found Spearman ρ = −0.1045 (p = 0.734, n = 13) between this hide-and-recover instrument and the organiser’s reported scores, and the reported champion ranks 13th of 13 on the instrument while ranking 1st on the board. HOLDOUT-DTI is therefore reported as HOLDOUT-DTI and never as a forecast; the forecast column is the PROJECTION from the measured credit algebra, which is a different instrument with a different failure mode.

5 · The instrument control, published because it did not reproduce

The pre-registration required single_B to reproduce the committed H61/H64 value 0.1745172876 to |Δ| ≤ 0.001. It measured 0.137947. That clause is unsatisfiable for a round that deliberately changes View B's channel set, and it is reported as FAILED rather than hidden. The model-free control that can reproduce across channel changes is the random arm: 0.072032 here against 0.080426 in H64, |Δ| = 0.0084, also outside 0.001. The residual difference is the eligible mask: the committed rounds read structural.FeatureStore.valid from work/r2/features, which is git-ignored and absent in a fresh sandbox, so this round used the all-19-bands-finite ∩ sample-submission-finite footprint and withheld 60,894 positives against H64's 53,186. Within-round paired comparisons are exact (identical folds, budget and masks for every arm); across-round level comparisons are approximate.
