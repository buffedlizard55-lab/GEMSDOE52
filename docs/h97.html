1 · Hypothesis and mechanism

directional semivariance anisotropy on the potential-field/subsurface bands is a subsurface texture that is not a copy of the surface texture; where View A is confident and View B abstains the fault may be buried beneath cover and absent from the surface-expression catalogue

Mechanism. fault damage zones lower density and destroy magnetite along strike, imprinting a preferred direction on the gravity and RTP-magnetic semivariance while alluvial cover removes the DEM expression

Named non-fault process that could mimic it. lithologic/intrusive contacts; basin-margin facies steps; survey flight-line and terrain-correction striping; paleochannel scour; isostatic/terrain-correction artefacts at block margins

2 · What was computed

Operator run_h82._gamma_stats (8-direction integer fan, sigma 3.0 px, lags 100/200/300/400/600 m), imported from the H82 round, never forked. View A = 4 potential-field/subsurface bands × 5 lags × 2 statistics = 40 channels; View B = 2 detrended-elevation bands = 20 channels. Both views also carry the shared cached feature store columns (36 View-A, 37 View-B), disjoint by construction.

7 · Limits (read before submitting)

  • This round's holdout score is 0.029460 [-0.179085 vs the best control 0.185968]. It did **not** clear the pre-registered promotion rule, so the file is a research candidate.
  • The hide-and-recover instrument withholds the catalogue faults, which were mapped from surface expression; the competition scores faults the catalogue lacks. This repository has measured that the instrument does not rank leaderboard performance (Spearman ≈ −0.10 over R4), so a holdout number is never a board forecast.
  • View A (potential field / subsurface) has failed the sufficiency gate in every round that reported it; H97 tests whether directional anisotropy changes that. The View-A out-of-quadrant AUCs are in the table above.
  • The lane census covers the locally available registry (82 unique rasters). The full 526-blob cross-repository census lives in a git-ignored receipt and was not re-fetched inside this round's time box (IR-H97-003).
  • No new external data was used. The one external layer ranked highest-unexplored (GDR 1391 two-metre temperature probes, DOI 10.15121/1881483) is not reachable from this sandbox (gdr.openei.org is not on the egress allowlist).
