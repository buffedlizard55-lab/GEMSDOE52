How to submit (for when a file is approved)

  1. Open the competition's submission page and choose New submission.
  2. Upload the .tif (or the single-GeoTIFF .zip). The portal requires a single-band GeoTIFF with the submission format's CRS, shape and geotransform.
  3. Enter the name and note from the table above.
  4. If the portal still reports a range error, copy its exact message into the review: this file's values are all in [0, 1], but we have not seen the portal's validator code.

Do not submit this file as a candidate for the leaderboard. A slot is a separate, owner-approved selector step (weekly cap on the submission page). This round has used 0 slots and holds 0 organiser receipts.
