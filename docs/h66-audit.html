Method

H66 uses a multi-data consensus approach that requires agreement among multiple independent data types:

  • Geophysical edge product: gravity gradient × magnetic gradient — requires BOTH to be present (consensus)
  • LiDAR scarp density: combined step, exposure, upface, and relief features smoothed to create density
  • Radiometric anomaly: K/Th and U/K deviations from background (hydrothermal alteration indicator)
  • Structural coherence: multi-scale (3-9 px) structure tensor coherence from DEM
  • Strike alignment: weighting favoring structures aligned with Basin-and-Range trend (100°)

The consensus requirement means a pixel is only high-confidence when multiple independent data types show signal. This is different from simple concordance (min of two views) or disagreement.

Hypothesis

H66: Structures that express across multiple independent data types (gravity, magnetics, LiDAR, radiometrics) with strike alignment to the Basin-and-Range trend are more likely to be real faults than structures that express in only one data type.

Mechanism: By requiring consensus among multiple data types, we reduce false positives from any single method. The strike alignment weighting reflects the regional structural trend.

Non-fault mimic: Lithologic contacts, survey artifacts, or drainage features that happen to align with regional strike and show coincident signals in multiple data types.

Difference from prior work: Prior submissions used two-view concordance (min of View A and View B) or disagreement. H66 uses consensus among 4+ independent data types with strike weighting.

Limits

  1. H66 has not been validated on the hide-and-recover holdout. The HOLDOUT-DTI is not yet measured.
  2. The prediction is generated using the methodological framework but without actual model training (training data not available in this environment).
  3. External radiometric data provenance has not been independently verified.
  4. No geologist has reviewed any specific structure.
