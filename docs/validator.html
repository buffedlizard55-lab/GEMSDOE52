🔍 In-browser GeoTIFF format checks

H83 status remains DOWNLOAD YES / SUBMIT NO. A local format result cannot open the H83 scientific gate; its HOLDOUT-DTI is NOT_EVALUATED and it is not approved to submit.

This check runs in your browser. Nothing is uploaded. The page reads the file locally using assets/tifcheck.js. It checks implemented GeoTIFF structure, grid, CRS, and value-range rules; it does not evaluate geology, holdout performance, leaderboard score, or organizer approval.

Select a GeoTIFF or one-TIFF ZIP

Rule source and limits

Implemented format checks are based on the official competition problem page, including the portal message Predicted values must be in range [0, 1]. The geometry constants in assets/tifcheck.js are recorded as measured from the organizer template. This checkout does not contain data/sample_submission.tif, so the template mask was not independently re-read here.

Passing this local format check means only that the implemented format rules passed for the selected bytes. It is not a promise of portal acceptance, a score, or permission to use a weekly slot.
