What could not be verified

  • No organiser score exists for any file in this repository. No file has ever been uploaded.
  • The public/private chunk boundary is not published, so |G| for the private chunk cannot be derived; the |G| ≈ 14,089 used in the algebra is a public-chunk quantity solved from two owner-reported scores of a strictly nested pair.
  • The three external uint8 rasters (lidar_scarp_features_u8, geodawn_rad_u8, geodawn_extensions_u8) carry no band descriptions at all. Their channels cannot be audited against a source, so H95 does not use them as learner inputs; it uses only bands whose identity the organiser's own file states.
