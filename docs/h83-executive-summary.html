Method

H83 uses multi-band structural concordance — a single integrated detector that identifies structural lineaments where multiple geophysical bands show coherent gradient orientation.

How it works:

  1. For each of 10 structural bands (gravity, magnetics, conductivity, strain, DEM derivatives), compute the structure tensor at 3 scales (σ = 1, 2, 4 pixels)
  2. Extract gradient magnitude and coherence (how linear the feature is, from the tensor eigenvalues)
  3. Combine into a single concordance score: strong gradients with high coherence across bands → likely structural feature
  4. Add LiDAR scarp features as high-confidence surface fault indicators
  5. Place 37,654 binary dots at 3px spacing on the highest-scoring locations, excluding the 200m catalogue ring

Why this is unique: Unlike B_DVA2 (variogram-based), this uses local structure tensor analysis. Unlike co-training (two competing views), this uses a single integrated detector. Unlike simple ridge detection, this leverages cross-band orientation agreement.

Bands used: det_elev, iso_grav_anom, depth_to_base_surf, iso_grav_anom_hg, det_elev_slope, tmi_vg, cond_surf, geod_2ndinv, tmi_hg, iso_grav_anom_vg

Named non-fault mimic: Lithological contacts can produce similar concordance signals. In the Great Basin, basin-margin faults often coincide with lithological boundaries.
