The verdict is right here.

The co-training lane (Blum & Mitchell, COLT ’98) has been closed five times in this repository by one gate: View A (gravity, magnetics, strain, seismicity) does not predict mapped faults on its own. H74 asks whether that gate was measuring the wrong thing. Mapped faults are surface-expressed by selection — they are in the catalogue because somebody saw them — which is exactly View B’s domain. So H74 re-tests sufficiency conditionally: View A’s out-of-quadrant AUC restricted to held-out truth that lies inside View B’s blind band. The shipped raster is the first properly nested co-training arm: View B’s ranking with the weakest φ of its budget swapped for View A’s confident cells where View B abstains.

In every fold, without exception, the ordering is A∣B-dark < A∣B-blind < A∣B-bright. View A is least informative exactly where View B is blind, and most informative exactly where View B is already confident. That is the opposite of the hypothesis H74 was built to test. It does not merely fail the bar — it forecloses the rescue argument that kept this lane open for six rounds: View A's apparent skill is a shadow of the same surface-expressed structures View B reads directly, not an independent subsurface channel that the catalogue under-samples. A buried-fault population that only gravity and magnetics can see would have produced the reverse ordering.

Note what did not fail: conditional independence. The two views' spatial-block out-of-fold errors on labelled negatives correlate at only |ρ| 0.1331. Co-training's independence precondition holds comfortably on this data; it is the sufficiency precondition — each view must be able to learn the target alone — that is refuted, and now refuted conditionally as well as globally.

Pseudo-labelling, independence and leakage

Conditional independence was tested first, as the lane requires: the two views’ spatial-block out-of-fold errors on labelled negatives correlate at max |ρ| 0.1331 over 2,089 blocks against an abandon bar of 0.6, so the exchange was allowed. Exactly one whole-segment pseudo-label exchange ran, in the direction the lane prescribes (confident donor → abstaining receiver), with whole spatial segments plus buffer so nothing reaches the evaluation region: 7,446 A→B and 7,995 B→A pseudo-labels across 4 folds (15,441 pseudo pixels in total). Leakage canary: the strongest single feature alone reaches AUC 0.6691 (B_slope_grad_3) against the 0.9 alarm — no alarm.

Disagreement is a budget stratification here, never a label source. That distinction is the single most expensive lesson in this repository: full co-training with pseudo-labels as training labels scored 0.0084 on the holdout, below a random control at 0.0253.

Geological reasoning for every A-only candidate

The lane identifies 842 A-only candidate cells, of which the shipped raster emits 76. Every candidate gets a row, whether or not the shipped arm emits it — the reasoning requirement is about the lane's discovery claims, not about which arm won the holdout. Each has a row in the reasoning CSV carrying its UTM 11N coordinates, both views’ out-of-fold ranks, measured depth-to-basement / gravity / RTP-magnetic / slope / radiometric percentiles, distance to the nearest mapped trace, a written interpretation, a named non-fault process that could mimic it, and the falsifier a Phase-2 reviewer would apply. Named mimics: a buried lithologic contact (Tertiary volcanics against basin fill) produces the same potential-field edge with no surface step and is not a fault; aeromagnetic flight-line and tie-line levelling residues are linear, surface-invisible, and strike with the survey plan. These rows are hypotheses from measured context, not field-verified geology.

The other half of the disagreement signal, and a falsifier that did not fire

The brief reads B-only disagreement (View B confident, View A abstaining) as a warning sign — roads, canals, powerlines, erosion lines. The shipped raster emits 450 such cells. Cultural lineaments are straight and overwhelmingly cardinal, so the test is the share of cells whose best-supported 600 m chord lies within 10° of due N–S or due E–W:

The falsifier did not fire. The B-only stratum is only +0.0223 more cardinal than a matched random control — not the pile-up that infrastructure would produce. On this survey the B-only cells are not measurably road-like, so the brief's road/erosion reading is not supported here. The audit is reported because it was run, not because it confirmed anything.

What this does and does not show

  • It shows a unique, lane-checked, portal-valid raster built inside the assigned co-training lane, with the conditional sufficiency test that five earlier rounds never ran.
  • It does not show a leaderboard gain. NO CERTIFIED LEADERBOARD GAIN. Nothing here is an organiser score.
  • Public board for context (public board, not organiser-confirmed): 0.3774 rank 1 (xiaofanhu), 0.3195 rank 7 (DARD), 0.2778 rank 13 (extradr19) — official leaderboard. The best owner-reported GEMSDOE file scored 0.2778; the forensic account of why is in knowledge/49.
  • Holdout prevalence (~1%) is far above competition prevalence (~0.15%), and the holdout instrument does not rank the board. Treat every number above as an internal measurement.
  • The holdout measured the ranking rule, not these bytes. line_support_B was scored on each fold's full allowed domain; the shipped raster applies the same rule inside a pool restricted to cross-family consensus ≤ 50, which is what makes it lane-feasible. That restriction moves almost every dot — Jaccard against the single_B placement is 0.0060 — so no number on this page describes the file you can download. That is the main reason it is research-only.
  • Support novelty against the prior union is 0.0000 (subset-of-union). On a registry holding 15 universal-coverage probe rasters, the 3 px union of all priors covers essentially the whole legal footprint, so no raster can show novel support. The meaningful uniqueness statement is the decoded-pattern one: distinct from every one of the 643 comparable rasters.
