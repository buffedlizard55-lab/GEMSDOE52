H66 / sources

Every input, pinned and checkable

Provenance of this page.

The H66 (structural coherence) round's two pages linked here, and the link was dead when that round merged. This page was added by the H67 session to close the dead link, not to author the H66 round's source list. It therefore lists only (a) the H66 round's own committed receipts and notes, which are the authoritative record of what it used, and (b) the pinned inputs and official sources that every round in this repository shares. Nothing here is a claim about H66 that its own receipts do not make.

Pinned inputs shared by every round

  • registry/data_manifest.json — 23 pinned mirrors with SHA-256; scripts/restore_data.py re-verifies them before any measurement. The H67 preflight re-checked all 23 with 0 mismatches (evidence/h67_preflight.json).
  • evidence/band_inventory.json — the 19 bands of training_features.tif as the file describes them. Band 6 is a radiometric total count, not a magnetic tilt derivative; that was measured, not assumed.
  • evidence/ctd5_prior_inventory.json — the frozen 526-blob census of every prior submission raster reachable from the owner's repositories, with the two ineligible entries flagged. This is the corpus every uniqueness and lane check runs against.
  • registry/irregularities.json — the irregularities register (IR-H66-001…010 are the H66 round's; IR-H67-001…011 are H67's).
  • registry/source_policy.json — what may be cited as a source, and what may not.

Official and external sources, for manual review

  • Competition problem page 967 — task definition, the distance-weighted Tversky metric (α 0.2, β 0.8, 300 m triangular kernel), the submission format (single-band float32, values in [0, 1], EPSG:32611, 100 m, same bounds as the training data, null outside), and the two-round prize structure in which the Final Round re-scores the same single submission against an expanded, expert-verified label set.
  • Public leaderboard — JavaScript-rendered; it cannot be read by a page fetch, so every score quoted in this repository is labelled OWNER-REPORTED or PUBLIC BOARD and never ORGANIZER-CONFIRMED.
  • Reference solution repository (DrivenData).
  • Competition forum.
  • USGS GeoDAWN airborne magnetic and radiometric surveys, northwestern Great Basin, Nevada — DOI 10.5066/P93LGLVQ. The source of the radiometric and magnetic grids behind the feature bands.
  • INGENIOUS / Great Basin Center for Geothermal Energy — the thermal-spring and well inventory used as an external layer.
  • EPSG:32611 — WGS 84 / UTM zone 11N, the competition's CRS.
  • Blum & Mitchell, "Combining Labeled and Unlabeled Data with Co-Training", COLT '98 — the method the co-training lane is built on, and whose sufficiency and conditional-independence assumptions this repository tests rather than assumes.
  • USGS 3D Elevation Program (1 m DEM) — named in knowledge/45 as the free official source the drainage-deflection hypothesis would require, and checked: not obtainable from this sandbox.

How to re-verify any number on this site

  1. .venv/bin/python scripts/restore_data.py — restores and SHA-256-verifies the pinned mirrors.
  2. .venv/bin/python scripts/run_h67.py — re-runs the H67 round end to end; it is a fixed point on decoded pixels (SHA-256 969bb11b7403d9c7… from two independent runs).
  3. .venv/bin/python scripts/h67_board_algebra.py — re-derives the 0.2778 board algebra from the restored bytes.
  4. .venv/bin/python -m pytest -q and .venv/bin/python scripts/check_site.py — the repository's own guards.

Local format validation is not organiser acceptance, and no number on this site is an organiser-confirmed score.
