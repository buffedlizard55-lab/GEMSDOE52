- No `work/` feature cache survived the checkout. Rehydrate it **once with the existing `structural.build`**, preserving its input/array hashes. Fix the shared band-6 view assignment and expose skipping unused optional profiles; no new transforms in H1. Band 6 is tagged as magnetic but previous mirror measurements match radiometric TC; provisionally isolate it in B, clearly flag that identity needs primary documentation. Exclude all external LiDAR/radiometric/SGMC/chemistry layers from training.
- Spatial split: shared `spatial.folds`; original 8-connected fault components are assigned whole, four large quadrants plus complete component tails. **80 px Euclidean training buffer**, larger than twice the 36 px feature support plus the 3 px kernel. Feature footprint eroded by the template's 36 px. Every catalogue-derived quantity (including any visible-fault distance) is computed only from the fold-visible catalogue. No catalogue-derived predictor is used here.
- Evaluation: original hidden components, never translated pseudo-truth; visible catalogue masked **pixel-exactly**, no guessed 200 m scoring exclusion. Train-negative clearance uses only visible faults. Report withheld-positive count, pooled TPw/FPw/FNw DTI with alpha 0.2 / beta 0.8 / 300 m triangular kernel, and 95% paired spatial-cluster bootstrap intervals (20 km clusters, 1,000 draws). Bootstrap conditional on these trained folds, not a leaderboard CI. No arithmetic mean of fold DTIs used as pooled DTI.
- Learner: CPU HistGradientBoostingClassifier, 90 iterations, learning rate 0.08, max_leaf_nodes 15, min_samples_leaf 40, L2 2, no random early stopping; seed 520810. Per fold max 20,000 positive and 60,000 catalogue-zero training samples. A weighted within four training-only cover-depth bins, B standard class balancing. Fit standard A as an additional control. Confidence ranks determined from 30,000 **training-domain** reference pixels, not held-out labels. Ranks are operating scores, NOT calibrated fault probabilities.
- Canary: before multivariate fitting, each used feature alone is evaluated on all outer folds using raw training-oriented ranks AND a univariate shallow boosting model (30 iterations, at most four leaves, training subsample cap 20,000). Any direction-insensitive AUC strictly above 0.90 is a leakage alarm; stop without claiming trustworthy model validation. Canary AUC is a HOLDOUT-DTI diagnostic, not DTI itself.
- Independence: correlate OOF negative MSE and false-positive rate across 5 km spatial blocks, using same held-out catalogue-zero pixels >500 m Euclidean from visible OR withheld faults. This clearance is for diagnostics only, never a model feature or emission constraint. Test Pearson and Spearman; **max absolute correlation >=0.60**, degeneracy or fewer than 20 usable blocks disables/abandons co-training. Proxy-negative absence is unverified; weak correlation does not prove independence or sufficient views.
- Candidate surface: `clip((rank_A - .80)/.20,0,1) * clip(1 - abs(rank_B-.50)/.35,0,1)`. It is asymmetric, peaks at high A / abstaining B, and suppresses confident B-only signals. Fixed single A, weighted A, B and max(A,B) controls; no search across mixtures. No prior raster is an input, target, core, or exclusion mask.
- Placement: reuse `nodes.emit_nodes`, minimum separation 3 px; global budget **12,000**, allocated to each evaluated region by eligible area. Same budget and placement for every control. Candidate eligibility requires positive surface; no zero-score fill. A shortfall is reported and blocks comparison/promotion. No optimizing the budget after results.
- Conditional pseudo-labels: only if the independence gate passes, one shared whole-component exchange, donor rank >=.95 and receiver rank [.35,.65], no known/held fault or sampled-label overlap, wholly inside train and a 50x50 spatial block; cap 2,000 pixels/direction, min 5 pixels/component, weight .25. Any independent-method gate failure stops the method; do not run alternative hypotheses as a workaround. The pre-exchange diagnostic field may still be exported **research-only** from already-computed OOF predictions. No post-failure retraining, prior copying, or forced promotion.
