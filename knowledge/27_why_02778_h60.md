## 1. The metric, reduced

From the official page (<https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/>),
α = 0.2, β = 0.8, R = 300 m. With `FNw = |G| − TPw` (an identity, pinned in
`tests/test_metric.py`):

```
DTI = T / ( 0.2·T + 0.2·(S − M) + 0.8·|G| )
T = Σ_g max_x p(x)k(d)   credited mass
S = Σ_x p(x)             emitted mass
M = Σ_x p(x)·max_g k(d)  emitted mass that sits within 300 m of some truth pixel
```

Two consequences decide everything:

* **Every emitted pixel more than 300 m from every truth pixel is a pure loss of 0.2.**
  The marginal rule `c·(1 − 0.2·DTI) > 0.2·DTI·(1 − m_x)` gives a bar of 0.0556 at
  DTI = 0.2778, and a pixel 300 m from all truth has `c = 0` and `m_x = 0`, so it always fails.
* **Binary `{0,1}` is optimal.** For a single pixel of weight λ on a truth pixel,
  `DTI = λk/(0.2λ + 0.8)` increases in λ, so any accepted pixel should carry 1.0.

## 3. The nested-pair algebra, and what it does and does not prove

For `A ⊂ B` with `Δ = S_B − S_A`, if the extra pixels carried no hit-mass at all
(`M_extra = 0`) and no credit, then `T·(1/s_B − 1/s_A) = 0.2·Δ`, giving

| pair | Δ px | implied `T` of the smaller file |
|---|---|---|
| ref → d28 | 6,436 | **5,223.1** |
| ref → h19_5 | 83,477 | 10,413.8 |
| d15 → tgc | 1,259 | 5,455.2 |

`T` decreases as the extra pixels are allowed to carry hit-mass, so the binding pair gives
**`T_ref ≤ 5,223`**, with equality only if the deleted 100–200 m ring had no truth within
300 m of it. Substituting into the champion's own score equation gives
`T = 0.0476·(S − M) + 0.1905·|G|`, so

* `M_ref = 0` → `|G| ≈ 18,006`
* `M_ref = T` → `|G| ≈ 19,313`
* `M_ref = S` → `|G| ≈ 27,418`

**Correction to `knowledge/01`.** That file reports `|G| = 14,088.7`. That value additionally
assumes `M = T` for *both* members of the nested pair, which is a coincidence-level
constraint, not a measurement; dropping it moves the bracket to **≈ 18,000 – 27,400**. Both
numbers are recorded here; the older one is not repeated as fact. What is robust and does not
depend on any of it: **the 100–200 m catalogue ring carried at most 5,223 − T worth of credit,
and deleting it raised the score by 2.6 % relative.**

## 4. A tomography attempt that failed, recorded so nobody repeats it

With 13 emissions and 13 scores, the metric linearises in a relaxed truth density `g`:

```
Σ_x g(x)·[ W_i(x)(1 + 0.6 s_i) + 0.2 s_i K_i(x) ] = s_i(0.2 S_i + 0.8 N)
W_i(x) = max_{y∈P_i} k(d(x,y)),   K_i(x) = Σ_{y∈P_i} k(d(x,y))
```

Assuming `g` uniform over the footprint, the thirteen priors imply `N` of **11,349 … 499,618**
(and several are negative, i.e. no `N` at all) — see `work/f3_tomography.py` output. Allowing
`g` to vary over 12,051 blocks with box bounds, the equality system is **infeasible at every
`N` from 1,000 to 60,000**. Thirteen scalars cannot localise a 14,000–27,000-pixel set, and
the first-order `E[max] ≈ Σ` approximation for `M` breaks exactly where `g` is concentrated,
which is where faults are. **Killed: recovering the hidden truth from public scores.**

Two statements, kept separate:

1. **The 0.2778 champion scores 0.00479 on hide-and-recover — below a random placeholder's

2. Across all 13 priors, Spearman(board, instrument) = **−0.099, p = 0.748, n = 13**: the
   instrument carries no usable rank information about the board. It is *not* inverted —
   saying that would overstate 13 points. What it measures is how much mass a field puts near
   the published catalogue, which the board does not reward.

## 7. So can we beat 0.2778?

Honestly: **not with a from-scratch model at the precision we can measure, and this repository
will not claim otherwise.** The champion's implied credit density is ≈ 5,223 / 37,654 =
**13.9 %** of emitted pixels carrying hit-mass. Our hide-and-recover precision at the same
budget is ≈ 7.0 % — but that number is measured against *catalogue* truth, where our model was
trained, so it is an upper bound for the off-catalogue truth the board actually uses. To reach
0.3195 with `|G| ≈ 18,000` requires `T > 3,861 + 0.051·S`, i.e. ≈ 14.8 % credit density at
37,654 px. We have no instrument that can show we are there, and the one instrument we have
ranks the champion below noise.

What is actually available, in order of certainty:

1. **Zero tax** — never emit within 200 m of a mapped trace. Free, measured, already applied.
2. **Mass discipline** — the board's own monotone mass/score relation. Applied by the amendment.
3. **Better off-catalogue detection** — the only lever that separates 0.28 from 0.37, and the
   one no instrument in this repository can currently measure. H60-2/3/4 are aimed at it; they
   are preregistered and their blocked AUCs are in `evidence/h60_views.json`.
