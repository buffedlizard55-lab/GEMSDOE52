The page lists strain, gravity, magnetic, seismic, topographic, conductivity, and radiometric-related inputs and specifies the GeoTIFF submission contract and distance-weighted Tversky metric.

## Frozen H72-A protocol

- **View A:** exactly `raw_band_04`, `raw_band_07`, `raw_band_08` from the shared cache. **View B:** exactly the shared H61/H71 `view_B_with_external` list, with band 6 kept in B under the repository's resolved identity policy. No feature addition, feature selection, threshold sweep, or external data.
- **E1 — leakage and fit:** run the shared per-feature leakage canary before trusting the model; any direction-insensitive single-feature holdout AUC above 0.90 is an alarm. Fit one model per view with the shared H61 learner and fixed seed, using label-blind whole-component/quadrant folds and the shared boundary buffer.
- **E2 — dependence, one exchange, holdout:** compute spatial-block out-of-fold error correlation on labelled negatives before exchange; if max absolute correlation exceeds 0.60, abandon co-training and do not exchange pseudo-labels. If allowed, perform exactly one shared whole-segment confident-to-abstaining exchange in each direction, with the shared buffer and fold/hidden-component exclusions. Compare strict A-only placement with `single_B`, `single_A`, `union_max`, and random controls on identical held-out folds, using the preregistered 1,264 dots per fold if every arm can fill it; otherwise mark the matched comparison invalid rather than rescuing the candidate outside its stratum.
- **HOLDOUT-DTI instrument:** `gems52-pooled-hide-v1`, pooled terms, α = 0.2, β = 0.8, 300 m triangular kernel, physical-block paired 95% bootstrap. Withheld positive count is measured from the actual run. Every reported DTI and CI must carry the evaluator version, withheld-positive count, and 95% CI; no public-board projection is permitted.
- **E3 — surface gate, placement, output:** before any final placement, compare the normalized OOF candidate surface against every supplied aligned registry raster. Stop as a duplicate if any Spearman rank correlation exceeds 0.90. Only if that passes, apply `nodes.spacing_select` with the registered 3 px minimum separation and the existing off-catalogue metric-aware domain. Run the final directed near-dot test against every registry raster; if more than 70% of final dots lie within 3 px of any one raster, record DUPLICATE/STOP and do not tune/re-place. Run the shared decoded-pattern uniqueness gate and explicit not-the-union test. Every emitted A-only dot gets a review row with measured strain context, coordinates, catalogue distance, and a clearly labeled geological hypothesis plus non-fault alternative.
- **Submission policy:** output is research-only unless every registered scientific, lane, uniqueness, and format gate passes. This run never uses a weekly slot or uploads anything. Even a passing research artifact only goes to a separate selector, as required by the competition protocol.
- **Budget:** at most three experiments (E1, E2, E3) and two hours; no post-result parameter search. A negative holdout or duplicate gate is a deliverable, not a reason to tweak the thresholds.
