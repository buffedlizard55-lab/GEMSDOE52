**Written before any H87 model fit.** This session stays in the brief's two-view co-training lane. The repository already contains many negative co-training rounds, so the estimates below are *ordinal priors*, not predicted scores. The exact 0.2778 filename-to-leaderboard attribution is not organizer-confirmed; see `knowledge/78_h85_session_review_2026-10-10.md` and the 2026-10-10 public-board snapshot.

## What is already known and what counts as untried

- Blum & Mitchell's sufficient-view and approximate conditional-independence assumptions are hypotheses to test, not properties to assume. The existing record repeatedly measures weak negative-error correlation but poor View-A sufficiency; H71 found one exchange reduced View-A OOF AUC. This H87 design therefore has a **fail-closed gate**: no exchange unless both views pass the predeclared sufficiency screen and the spatial-block negative-error test.
- H82's directional variogram anisotropy (DVA-2) was measured in a *mixed* learner arm that included DEM, slope, gravity, cover-depth and gravity-gradient bands. It did **not** establish that a strictly geophysical View A can teach a strictly surface/radiometric View B. H87's candidate is that previously unmeasured, disjoint-view question; it is not a claim that the DVA transform itself is new.
- Repository-wide search before this registration found related gravity/magnetic/strain transforms and a prior proposal for conductivity-edge junctions. H87 does not claim global novelty. The experiment below is the top candidate only because its precise view separation and holdout test are absent from the executed receipts inspected here.

Ordinal “low–medium” is a qualitative hypothesis priority, not a score projection.

## Frozen H87-A protocol

1. **Data/cache.** Use the shared `gems52.structural.FeatureStore` under `work/r2/features`; if absent, build it once with `gems52.structural.build` from the manifest-pinned competition mirror. The source pins prove byte integrity against the owner's mirror, **not organizer authentication**. The B feature list comes from the store's `view_B` only. H87 adds A-only DVA columns for bands 2, 13, 15, 17, 7 and 16; no band 6/12/19 feature may enter A, and no A feature may enter B.
2. **DVA definition.** Eight fixed integer directions `(0,1),(1,1),(1,0),(1,-1),(1,2),(2,1),(2,-1),(1,-2)`; lags `{1,2,3,4,6}` pixels; 3 px Gaussian averaging. For each A band and lag, retain `(max γ - min γ)/(max γ + min γ + 1e-9)` and `log10(mean γ + 1e-9)`. Band values are standardized on the unlabeled eligible footprint only. No label enters feature construction or normalization. These are scale/anisotropy covariates, not fault labels.
3. **Leakage canary.** AUC-test each individual A and B input channel against each fold's held-out positives and held-out catalogue-zero proxies at least 5 px from visible traces. Direction-insensitive AUC > 0.90 is a leakage alarm and stops that feature pending proof. The proxy-negative label is not verified absence.
4. **Fold geometry and training.** `gems52.spatial.folds` label-blind-quadrants-v2, whole 8-connected fault components hidden, 80 px train/evaluation buffer. Derive every catalogue-dependent mask from that fold's visible labels. Train each view separately on the fold's visible labels in `fold['train']`; negatives exclude all labelled pixels and a 5 px visible-trace collar. No sample from a held-out segment, evaluation region, or buffer may enter a fit or exchange.
5. **View sufficiency.** Per-view region OOF AUC is a diagnostic, not DTI. Require each view's mean OOF AUC >= 0.60 before exchange. This is a conservative preregistered gate reflecting the theorem's sufficiency premise and prior H63/H82 practice, not an organizer threshold. Failure closes pseudo-label exchange.
6. **Independence.** Correlate the two views' OOF error statistics on the *same* held-out catalogue-zero negatives in 50×50 px blocks, minimum 32 negatives per block. Use the shared `gems52.spatial.negative_block_errors` and `independence`; abandon exchange if any defined Pearson/Spearman block error correlation has absolute value >= 0.60, fewer than 20 blocks are usable, or a statistic is undefined. Low proxy-error correlation is not proof of conditional independence.
7. **Exchange, only if both gates pass.** One round only. Donor rank >= 0.95 and receiver rank in [0.35,0.65]; whole 8-connected pseudo segments of at least 5 pixels, entirely within one 50×50 block and the fold's training region, outside the held-out region/components and the visible-catalogue 4 px collar; cap 2,000 pseudo pixels per direction per fold. Record every selected segment. Otherwise zero pseudo labels, with reason.
8. **Holdout and controls.** Compare A-only disagreement `rank(A) >= 0.95 AND rank(B) in [0.35,0.65]`, `single_A`, `single_B`, `max(A,B)` union and matched random at exactly 9,400 placed pixels per fold, where possible. Placement is `gems52.nodes.spacing_select`, 3 px minimum separation, outside the visible-catalogue 200 m ring. Score only with `gems52.evaluate_holdout` / `gems52-pooled-hide-v1`, pooled alpha 0.2, beta 0.8, 300 m triangular kernel; 95% paired 20 km physical-block bootstrap, 1,000 draws. Report all per-arm DTI with withheld-positive count and CI. If any arm cannot fill the fixed budget, do not rescue it with a different budget; mark that comparison invalid.
9. **Submission artifact.** Only after holdout, refit full-data view models for a research-only A-only disagreement field; place at most the preregistered 37,654 cells using 3 px spacing and an off-catalogue 200 m ring. Normalize to finite float32 `[0,1]` (binary 0/1). Write through `gems52.submission_writer`, reopen and validate against the sample grid, run decoded-pixel uniqueness, lane check on the surface **before** placement and on final dots, and compare the result with each view and their union. Any lane threshold violation is logged as DUPLICATE/STOP. There is no competition slot in this experiment.
10. **Geological review and verdict.** Write one review row for every emitted A-only pixel, with coordinates, view ranks, available feature values, a conditional geological interpretation, a specific non-fault mimic, and a falsifier. These are candidate review targets, not verified faults/vents. Verdict is `negative` unless a predeclared, same-fold holdout gate beats the best same-fold baseline and every format/lane/uniqueness check passes; no post-hoc selection.
11. **Budget and claim discipline.** At most 3 experiments or 2 hours, whichever comes first. No upload slot. Every score is labelled HOLDOUT-DTI (evaluator version, withheld positives, 95% CI); public-board scores are labelled PUBLIC-BOARD/owner-reported unless copied from an organizer receipt. A projection is never called a score.
